# userscript

## 사용 방법

1. 브라우저에 맞는 확장 프로그램을 설치합니다.
   - [Tampermonkey](https://www.tampermonkey.net/): [Chrome Web Store][tampermonkey_chrome], [Edge Addons][tampermonkey_edge], [Safari][tampermonkey_safari], [Firefox Add-ons][tampermonkey_firefox]
   - [Violentmonkey](https://violentmonkey.github.io/): [Chrome Web Store][violentmonkey_chrome], [Edge Addons][violentmonkey_edge], [Firefox Add-ons][violentmonkey_firefox]
   - [Greasemonkey](https://www.greasespot.net/): [Firefox Add-ons][greasemonkey_firefox]
   - [Userscripts](https://github.com/quoid/userscripts): [Safari][userscripts_safari]
2. 아래 목록에서 원하는 유저스크립트를 설치하거나
   src/<스크립트 이름>/dist 폴더 내에 있는 설치하고 싶은 스크립트(`<스크립트 이름>.user.js`)를 찾은 뒤 `Raw` 버튼을 눌러 설치하면 끝!
